# About the project

This project was presented in SIBGRAPI 2026 conferece as an WIP project.
This project study the effectiveness of irregular superpixel methods in image vectorization process. Our results shows that irregular superpixel methods shows better results than regular ones.

# Dependeces

This project is powered by SICLE and SLIC superpixel segmentation methods.
